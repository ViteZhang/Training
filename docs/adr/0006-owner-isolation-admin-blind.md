# 0006 用户内容按 owner 隔离；后台默认不可见，只能经用户授权 72 小时查看

- 日期：2026-10-01
- 状态：已采纳

## 背景

「数据只属于用户」是产品承诺（PRD 2.3、16.2）：自建内容仅本人可见，后台默认看不到。

## 决定

- 所有用户内容表带 owner_user_id，并对 users 外键级联删除（注销冷静期到期后物理删除；OSS 原件由定时任务另行删除）
- 每条查询用户内容的 sqlc 查询都带 owner_user_id 条件；访问别人的 ID 返回 404（不是 403，避免泄露存在性）
- 每个用户内容接口都有「拿别人的 ID 访问返回 404」的集成测试
- 后台（admin 包）不提供读取用户资料、题目、作答原文的查询；只有 content_access_grants 有效期内（72 小时）的授权查看接口能读，每次读写 content_access_logs 并给用户发消息；日志保留 180 天
- 后台统计只读 stats_hourly 汇总表，由 Worker 每小时汇总，不实时扫用户内容表
- 日志不记录手机号明文、作答原文、资料原文；ai_calls 只存元数据与用户 ID 哈希

## 放弃的方案与原因

- 数据库行级安全：MySQL 没有原生支持，靠视图或触发器难以维护
- 用 403 区分「存在但无权」：会泄露别人内容的存在性

## 影响

- 新增用户内容表必须带 owner_user_id 与外键；审查清单逐条检查
