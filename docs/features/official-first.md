# 考研Training 官方题库需求文档（PRD v3 增补）
2026-11-02 · 
## 概述
本文档是 PRD v3 的增补：官方题库从「有运营资源时再做」改为新用户的第一站，同时为没有官方题库的用户提供「先体验、再导入」的路径。本文未提到的规则一律沿用 PRD v3。
为什么改。 测试中用户卡在自建题库的上传环节，原因有三：资料在微信、网盘里，手机上选不到；担心资料隐私或被平台拿去做成商品；要先上传、等解析、再核对，才能刷到第一道题，价值出现得太晚。
目标（2027 研考初试前）：
- 种子用户报考的文学、哲学院校专业上线完整的官方题库，第一套为四川大学哲学专业。
- 每个新用户在注册当天都能体验到一次按采分点批改，无论他的课有没有官方题库。
- 提升新用户首日完成批改率和体验后的资料导入率。
变更摘要：
- 引导 1.1：院校专业从选填改为分流入口。
- 新增：有官方题库的首题体验；体验一道题；学科通用体验题；申请收录。
- 上传页 1.5：隐私承诺前置，增加微信文件导入说明。
- 后台新增：申请收录、AI 解析导入、通用体验题管理。
- 官方题库对所有用户开放，内容一次做完整（含知识框架与背诵）。
依据：Training 官方题库产品方案、考研Training App 设计稿「8-官方题库（新增）」页。

## 功能需求 · App
新用户在 1.1 选完院校和专业课后分三条路：有官方题库 → 1.1a；没有 → 1.1c；院校未定 → 1.10。三条路的终点都是完成一次按采分点批改。
### 引导分流
页面
功能点与规则
1.1 选院校和考试科目
选考试年份；搜索并选择目标院校（必填，院校未定时走底部「院校还没定，先随便看看」；库里没有的院校可以直接用输入的名称）；列出这所院校能选的考试科目，可多选，最多 4 门：本校的科目（院校自命题 + 本校登记使用的全国统考）少于 4 门时直接列出，下面另列「全国统考科目」；4 门及以上先按学科分组（本校的学科在前，有统考的学科在后），每个学科下列本校自命题科目和这个学科的统考科目；本校已有同代码自命题卷时不列统考版。每门课标「有官方题库」或「暂无官方题库」，统考科目标「全国统考」，自命题科目显示适用专业。列表里没有时可手动添加（代码 + 名称，规则同 PRD v3 1.1），填的代码是统考代码时提示「是全国统考的 333 教育综合吗？」，可以直接选统考科目。「报考专业」选填，只用来展示和统计，不影响匹配题库。「下一步」按匹配结果跳 1.1a 或 1.1c（T50）
1.1a 匹配到官方题库
显示院校专业、官方题库版本、真题年份数、知识点数、模拟卷套数；列出包含内容，注明「所有用户免费使用，不需要上传任何资料」；同时选了无官方题库的课时在下方列出，点击进 1.1c；主按钮「添加官方题库，先做一道真题」→ 1.1b；次按钮「不用，我导入自己的资料」→ 1.5
1.1b 首题
从官方题库自动取一道名词解释真题（按高频考点优先）；标「官方」与年份、题型、分值；支持打字和拍手写稿；提交后进入 4.7 批改结果；右上角可跳过，跳过进入 3.1e；这次批改不扣额度
1.1c 暂无官方题库
三个入口：体验一道题（主推荐，→ 1.9）、用示例题试试（→ 1.10）、申请收录（→ 1.11）；底部「直接导入我的资料」→ 1.4；体验次数用完后，前两个入口显示「已体验」并不可点
引导中的 1.2 目标分、1.3 备考安排移到首次批改之后，可跳过，规则不变。

7.17 AI 解析导入

### 考试科目库（原「院校专业课库」，放在后台「配置」分组；2026-11-06 改为按考试科目维护，T50）
1.1 的院校搜索和考试科目列表都来自后台维护的考试科目库，由运营手工维护，不接外部数据。题库只关心考哪套卷子，不关心专业：很多专业共用同一套卷子。
- 一套卷子是一条考试科目：命题方式（院校自命题 / 全国统考）、院校（统考不填）、学科、考试代码、科目名称、参考书目（可多本）、适用年份（为空表示各年通用；科目名或参考书逐年变化时按年份分开录，用户自己判断）、适用专业（选填，只用来展示和搜索）。
- 学科从固定选项里选（学科门类：哲学、经济学、法学、教育学、文学、历史学、理学、工学、农学、医学、军事学、管理学、艺术学、交叉学科），不再细分。
- 去重：自命题按「院校 + 代码 + 年份」，统考按「代码 + 年份」；没有代码时按名称。
- 全国统考（如 311 教育学专业基础、312 心理学专业基础、313 历史学基础、333 教育综合）全国只录一条，只立一个官方题库项目，所有院校的考生共用。代码不能用来判断是不是统考（333 也有院校自命题的），由后台明确标出命题方式。管理类、经济类联考（199、396 等）不在文科专业课范围内，不收。
- 院校可以登记「本校使用某门统考」（选填）：登记后这所院校的搜索结果和科目数算上它；没登记的院校在 1.1 选到这个学科时也能看到统考科目。
- 每条考试科目自动显示官方题库状态（有 / 无 / 生产中）和在 1.1 选了它的人数，统考科目另显示登记的院校数；从这一行直接「立项做官方题库」，不用再填院校、代码、名称（统考立项的院校记为「全国统考」）。
- 用户在 1.1 手动添加的课程按「院校 + 代码」汇总成「待入库」列表，运营核对后一键入库、合并到已有科目，或合并到统考科目（同时把这所院校登记为使用该统考）。
- 7.10 需求洞察改按「院校 + 代码」统计，统考只按代码统计。
- 第一批先录入四川大学哲学：662 中国哲学史、812 西方哲学史，以及种子用户报考的其他院校专业。
## 业务规则
标「默认值」的参数都在后台 7.8 规则参数里可配置。
### 体验与额度
- 体验一道题和通用体验题共用一个次数：每个账号 1 次，以提交批改为准，批改失败不计次。
- 体验不消耗任何免费额度（解析、批改、AI 出题）。
- 1.1b 官方题库首题的批改不扣额度，不占体验次数。
- 体验中的 AI 参考答案和批改结果标「仅供参考」，不计入预估分（同 PRD v3 11.16）。
- 用户选择加入自建题库后，题目、采分点和这次作答都保留；答案来源为「AI 参考答案 · 待确认」或「来自你的资料」（用户填了参考答案时）。选择不保存时全部删除。
### AI 出题（通用体验题）
- 已覆盖学科（第一批哲学、文学）：AI 按方向批量生成初稿，团队在 7.18 审核后上线。
- 未覆盖学科：AI 按用户所选专业课和参考教材现场生成一道题，题目标「AI 出题」，参考答案标「AI 参考答案」。
- 同一专业课的现场生成结果缓存复用，控制成本和等待时间；缓存题进入 7.18「AI 出题缓存」，可抽检、下线。
- 模型使用 DeepSeek。
### 补充资料提示（3.1e）
- 触发条件（默认值）：某板块在用户最近 14 天内作答 ≥ 5 题、得分率 &lt; 60%，且该板块官方题 &lt; 5 道。
- 其他触发：批改异议原因为「和我们老师讲的不一样」；错题本达到 30 题（默认值）。
- 每次只显示一条；用户点「以后再说」后，同一板块 7 天内不再提示。注册当天不提示。
### 申请收录
- 按「院校 + 专业课名称」归并，有代码时优先按代码。
- 超过 24 小时未处理：标红，进入 7.1「需要处理」。
- 同一门课申请人数达到阈值（默认 3 人）：标「建议立项」并推送企业微信群。
- 申请人是付费用户或种子用户时单独标注；种子用户由运营在 7.2 用户详情中标记。
- 处理状态变化（已立项、已上线、暂不收录）时消息通知所有申请人；官方题库上线时，申请人和在 1.1 选了该课的用户都收到通知。
### 必答与限选（T51，2026-11-06）
- 有的真题卷按专业分组出题（如北师大 808 中国语言文学：名词解释、简答所有考生都答；论述题分七组，「请选择文艺学、比较文学与世界文学专业的考生作答」，回答非报考专业不得分）。
- 题目分两种：必答题（没有分组）和限选题（记组名，如「第一组」，以及这一组适用的专业）。后台 7.12 录题、7.17 真题卷解析（按分组标题自动识别）、表格导入（「限选分组」「适用专业」两列，选填）都能标限选题。
- 用户添加官方题库时，限选题只复制与这门课报考方向匹配的那一组；同一年哪一组都对不上时全部保留；没填报考方向时各组都保留（与用户自己导入时选「不区分方向」一致）。
- 1.1 选填的「报考专业」就是这门课的报考方向（已有方向的不覆盖）。用户之后在备考设置或导入核对页改方向时，官方题库的限选题跟着换：不匹配的组下线（作答记录保留），改回来时恢复。
- App 上限选题标「限选 · 第一组」，详情写明「限选题（第一组）：……专业的考生作答，回答非报考专业不得分」；整卷作答时，卷子里有限选题的，其余题标「必答」。
### 资料导入：Markdown 与重复试题（T52，2026-11-06）
- 后台 7.17 上传资料支持 Markdown（.md）：团队可以先把资料整理成 md 再上传，解析前自动去掉排版标记（标题符号、加粗、链接网址、图片等），表格逐行转成文字。粘贴的文字同样处理。
- 同一年份的同一道题算重复（题干相同，或同题型且题干几乎一样）：核对区标「重复」并写明和哪份资料第几题、已发布的官方题或草稿重复，可以一键驳回。只标还没核对的题；两份资料都没核对时只标后传的。
- 不同年份考了同一题不算重复（真题本来就会重考），只提示「某年也考过」。
- 上传真题卷时，本项目已有同一年份的真题卷就先提醒，可以继续上传（可能是修正过的版本）。
### 补答案与教材（T53，2026-11-06）
- AI 补的参考答案优先引用项目「关联教材」里已发布、有索引的教材；没用上教材时核对区逐题写明原因：没关联教材、关联的教材不能检索（逐本说明）、没检索到相关段落、段落与本题不相关、引用核对没通过等。
- 先导入、后关联教材时，可以逐题或整份「按关联教材重新生成」：只换 AI 生成的答案，原文给的答案不动，原文给的采分点保留。
- 上传时勾了「缺答案时由 AI 生成」、项目却没有能检索的关联教材，先提醒去关联。
- 没有指定参考书的科目（只有考纲）、学长学姐的经验总结怎么用，见 open-questions Q20（T55 实现）。
### 官方题库开放与共存

- 批改、AI 解读、组卷等 AI 功能仍按现有额度与会员规则（PRD v3 第 13 节）。
- 官方真题的参考答案经团队审核，来源标「官方」，批改结果计入预估分。

### 内容来源与隐私承诺
- 官方题库只使用公开真题、团队自编内容和有书面授权的资料，不使用任何用户上传的内容。技术上，7.17 的解析任务与用户端解析数据分开存放。
