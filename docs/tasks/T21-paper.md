# T21 整卷与模拟考试

- 仓库：后端 + 前端（先后端，后前端）
- 依赖：T18
- 计划完成：10/11
- 状态：开发完成（后台识别自动化验证通过，真机待复验）

## 目标

用户能用导入的真题卷或 AI 组卷做整卷练习和模拟考试。

## 范围 · 后端部分（在 peetraining-server 里做，先合并并打契约标签）

- 真题卷列表（含缺题卷按实际满分计分说明）；AI 组卷（标准卷、针对卷，11.10），不够时补变式题并标出
- 同一时间只能一套进行中；练习模式可暂停；模拟考试服务端 deadline_at，离开继续计时，10 分钟内可恢复一次
- 每题用时记录；时间提醒点按 11.9 计算
- 交卷：客观题即时出分，主观题 Worker 异步批改（约 2 分钟），完成发消息；整卷批改额度每周 1 套

## 2026-10-30 手写稿切题后后台识别

- 新增迁移 `00027_paper_handwriting.sql`，按用户、考试、题号保存原图对象键、幂等键、拍照顺序、识别结果与确认状态。
- 登记接口仅允许截止时间前新增照片；同一幂等键恢复原任务。`paper:handwriting` Worker 复用现有视觉大模型能力，独立于 App 页面执行，最多自动重试 3 次。
- 交卷仍严格锁定 deadline；整卷 Worker 在批改前补跑、按拍摄先后默认确认未核对照片。识别失败保留整卷状态，通过原有恢复批改重试，不按空白计零分、不重复扣次。
- MySQL 连接锁避免两个 Worker 同时识别同一张稿件；确认与追加在事务中完成，响应丢失后重复确认不重复追加。核对编辑可只保存，延后按拍照顺序统一追加。
