# T07 备考档案、规则参数与功能开关

- 仓库：后端 + 前端（先后端，后前端）
- 依赖：T03
- 计划完成：10/7
- 状态：未开始

## 目标

新用户能设置专业课、目标分、阶段和时长；所有可调参数和开关都在服务端。

## 范围 · 后端部分（在 peetraining-server 里做，先合并并打契约标签）

- 专业课：名称、代码（选填）、满分、目标分，最多 4 门，免费版最多 3 门（PRD v3 13.1）；考试年份；目标院校专业（选填）
- 备考档案：阶段（含是否手动）、每日时长、提醒时间；初试日期按年份从配置读取
- rule_params 表与读取缓存，初始值按 PRD v3 第 11、13 节写入
- feature_flags：全部 / 指定用户；App 启动拉取；关闭时相关接口返回 404；写 ADR 0009

## 范围 · 前端部分（在 peetraining-web 里做，先执行 pnpm gen:api）

- 1.1 你考哪门专业课、1.2 设定目标分、1.3 备考安排（引导进度条 1–3 / 5）
- 6.9 备考设置（删除专业课时的二次确认文案按设计稿）
- 引导中途退出后再次启动回到中断步骤

## 验收

- 新用户能完成 1.1–1.3，数据正确保存；可跳过目标分
- 改阶段或时长从次日生效，改目标分立即生效
- 对指定账号打开一个开关后，只有该账号能看到对应入口

## 不做
