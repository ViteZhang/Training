# T18 主观题批改、失分诊断与异议

- 仓库：后端 + 前端（先后端，后前端）
- 依赖：T17
- 计划完成：10/10
- 状态：未开始

## 目标

按用户资料里的采分点批改，这是产品的核心。

## 范围 · 后端部分（在 peetraining-server 里做，先合并并打契约标签）

- 主观题批改：逐采分点判定命中 / 部分 / 遗漏，引用考生原话，给建议；校验分值上限、总分、引用存在；≤ 8 秒
- 额度：每天免费 3 次，扣额度与写结果同一事务；失败不扣；待批改队列（额度用尽时存）
- 失分诊断按 11.7；更新掌握分与错题本
- 异议：改采分点后重批、提交复核重批，都不扣次数；授权勾选写 content_access_grants
- cmd/eval grading：读人工评分样本，输出偏差 ≤ 1 分比例与重批一致性

## 范围 · 前端部分（在 peetraining-web 里做，先执行 pnpm gen:api）
