# T39 教材文件导入与 PDF 大模型识别

- 状态：已实现并完成隔离及本地浏览器验证；真实模型质量待 T43
- 依赖：T38
- 授权：已确认需求与设计，用户要求持续开发。

## 实现计划

1. 导入契约先行：限制、私有预签名上传、提交、进度、失败重试与结果采用。
2. 文件及逐页任务落库，幂等提交；识别结果不直接覆盖草稿，按版本检查后明确采用。
3. PDF 仅渲染页面，全部页面视觉大模型识别；保留页序、原件、页图与不确定片段；DOCX/TXT/MD 用确定性取文。
4. Worker 任务逐页检查点与并发保护；自动及手动重试复用已完成页面；API 与 Worker 间入队失败可恢复。
5. 后台上传、任务状态、识别结果预览与明确导入草稿；模型输出校验、隔离集成、mock 评测和交互验证。

## 验收

- 文字 PDF、扫描 PDF 每页均走教材视觉模型，不调用传统 OCR。
- 不接受任意 OSS 键，跨教材/版本/修订 ID 组合返回 404；受后台角色保护。
- 实际文件大小与声明核对，服务端限制大小/页数/批次；保留全部页序，失败不补写。
- 重试不重复拼接已完成原文；处理中不覆盖人工草稿；采用识别结果检查草稿版本。
- 未解决的不确定内容保留标记，校对须显式确认；已发布修订不可写。
- 测试不连接生产、不读取 `.env.local`。真实模型准确率与费用在 T43 验收。

## 配置与人工关口

默认：50 MB / 文件、1000 页 / 文件、50 文件 / 修订、全局并发 2、每天 PDF 页处理 2000 次；可在 rule_params.textbook_import_limits 修改。每日预算包含失败页面的再次处理，模型内部输出校验最多额外重试一次。新建队列投递最多自动重试 3 次，手动提交/重试最多 5 轮；成功页面不重复识别。Word/TXT/MD 的文本单元不充当纸质页码。

真实 PDF 图片在 mock 模型下明确失败，不能用测试夹具冒充教材。生产验收需已授权教材与真实视觉模型，核对页序、空白页、表格、缺字及费用。发布前仅按增量方式执行 00030，API 与 Worker 同步更新；本轮没有生产迁移或部署。
