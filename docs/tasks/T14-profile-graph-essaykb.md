# T14 考情分析、知识图谱、作文知识库

- 仓库：后端 + 前端（先后端，后前端）
- 依赖：T10、T11
- 计划完成：10/10
- 状态：未开始

## 目标

用用户自己的真题告诉他这门课怎么考。

## 范围 · 后端部分（在 peetraining-server 里做，先合并并打契约标签）

- 考情统计按 PRD v3 11.11：题型结构与建议用时、板块分值占比、高频考点、缺资料提醒、出题风格标签（AI）
- 知识关联：AI 按章节和同题出现生成关联，用户可调整
- 作文知识库接口：写作方法、素材、范文

## 范围 · 前端部分（在 peetraining-web 里做，先执行 pnpm gen:api）

- 3.8 考情分析、3.9 知识图谱（可缩放、点节点、筛选）、3.10 作文知识库
