# T12 导入流程页面

- 仓库：前端（peetraining-web）
- 依赖：T07、T10
- 计划完成：10/9
- 状态：审查中（真机验证留到最后统一做）

## 目标

用户能从选文件一路走到「题库建好了」。

## 范围

- 1.4 选择导入方式、1.5 选择文件（文件、相册、拍照、粘贴；上传进度；使用权勾选）、1.5b 粘贴文字导入
- 1.6 AI 解析中（逐文件进度、可离开、设学习提醒）、1.6b 部分文件识别失败
- 1.7 确认导入结果（筛选、逐题状态、确认入库）、1.7b 核对主观题采分点（改分值、增删、合计校验、AI 生成参考答案）
- 1.8 题库建好了（「先做个摸底测」入口按钮在本卡做，摸底测会话在 T17 接通）
- 首页 2.1b 题库整理中、2.1c 还没导入资料
- 额度不足在开始前弹出；相机、相册权限说明

## 参考

- docs/prd.md 第 6 节模块 1（1.4–1.8）、第 7 节 2.1b–2.1c
- docs/design/pages/m1_*、m2_home_parsing、m2_home_empty

## 验收

- 真机上传一份 Word、一份 PDF、三张照片，看到进度、确认、入库，首页出现题库
- 离开解析页后回到首页显示 2.1b，解析完成后能继续确认
- 所有页面的五种状态齐全

## 不做

- 卡片范围以外的页面、接口和重构；发现需要的，记到 docs/open-questions.md

## 记录（开发中填写）

- 实现要点：
  - 路由 app/import：index（1.4，可带 subjectId 预选）→ files（1.5）→ paste（1.5b）→ job/[id]（1.6 / 1.6b）→ confirm/[id]（1.7）→ item/[id]（1.7b）→ done/[id]（1.8）；引导第 4 步 (onboarding)/import 复用 1.4（ModeStep），引导中走到 1.8 时结束引导
  - 1.5：文件（expo-document-picker，.doc / .xls 提示另存）、相册与拍照（expo-image-picker，先弹权限说明，拍照被拒给「从相册选」）、粘贴；单次上限前端先挡一遍；使用权勾选；上传：SHA-256（expo-crypto）→ 申请直传 → File.upload PUT 显示进度 → 回调确认；重复文件显示「之前传过，不重复扣额度」；解析额度不足（402）弹开会员，写明需要与剩余页数
  - 1.6：每 3 秒刷新进度，每个文件三段步骤与排队状态、预计剩余时间；等待时设学习提醒（07:30 / 12:30 / 20:00，保存到备考档案，开启前请求通知权限）；AI 判断为作文资料时提示；「先核对已识别的 N 条」「先进入 App，好了通知我」
  - 1.6b：失败与部分识别的文件显示原因，可重新识别、保留或移除，附拍照建议
  - 1.7：汇总、全部 / 需核对 / 主观题 / 客观题筛选（带数量）、分页加载、每条题型分值状态与说明；确认入库，题目导入额度不足弹开会员
  - 1.7b：出处（文件 + 页码）、题干与参考答案可改并标来源、采分点逐条改内容与分值、增删、合计 ≠ 分值时标红并禁止确认；缺答案时 AI 生成（生成中状态、额度不足弹层）；知识点归属可改；可删除；知识点与作文资料条目可确认或删除
  - 1.8：题数、知识点数、待核对数、组成的真题卷；摸底测按钮（会话在 T17 接通，先提示）；还没导入的专业课给继续导入
  - 首页：2.1c 还没导入资料（导入入口、先导入什么、我的题库）、2.1b 题库整理中（进度、看进度 / 去核对、我的题库）；正常状态在 T16
  - 新增依赖（Expo SDK 57 官方模块）：expo-document-picker、expo-image-picker、expo-file-system、expo-notifications；app.config.ts 加对应插件与权限文案

  - 已有测试套件（auth、onboarding）结束时有一个定时器未清理的警告，非本卡引入，未改
