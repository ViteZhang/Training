# T42 APP 教材匹配、答案出处、候选比较与官方项目关联
- 状态：代码已实现，发布验收待 T43；依赖：T41；依据：已确认官方教材库 PRD 与交互稿。
## 范围
- 书名自由保存，匹配与建议异步且静默；明确采用的版本可锁定，沿用既有 APP 规范。
- 答案只展示生成快照中的出处及授权摘录；主动更新异步恢复、比较答案/采分点/来源，采用后待确认。
- 官方项目关联已发布明确版次，候选经草稿与发布保留引用；旧私有素材迁移为待校对草稿，不自动发布。
## 验收
- 教材未匹配/接口离线仍可保存原书名；跨用户访问 404。
- 引用不随当前书名变化；无依据和历史未知区分；撤销摘录不展示原文。
- 候选生成前说明扣次；退出不覆盖；采用/放弃幂等；冲突保留原答案。
- 关联不复制和删除公共教材；旧素材迁移可重复运行且不丢原记录。
