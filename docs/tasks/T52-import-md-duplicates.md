# T52 后台资料导入支持 Markdown；重复试题识别（11 月 6 日产品更新）

- 仓库：后端 + 管理后台（云效 peetraining-admin）；App 不改（只同步接口契约副本）
- 依赖：T47、T49、T51
- 状态：开发完成

## 背景

- 团队准备把后台上传的资料都先整理成 Markdown：md 本身就是文字，不用再走 PDF 解析或拍照识别，省时也省钱。
- 同一年的真题卷传了两次，会解析出两份一样的题，核对区没有任何提示。用户端导入一直有查重（importer 第 10 步），后台 7.17 没有。

需求见 [official-first.md「资料导入：Markdown 与重复试题」](../features/official-first.md)。

## 范围 · 后端

- 迁移 00044：official_import_files.format 加 md
- 7.17 上传 .md 文件（UTF-8，走 OSS 直传 + confirm），或带 text 直接提交；解析前去掉排版标记：标题符号、加粗斜体、引用、列表符号、
  分隔线、代码块围栏、图片、链接网址、HTML 标签，表格逐行转成文字（单元格之间空两格）。粘贴的 text 同样处理
- 题型标题、题号、「第一组：请选择……」这些行原样保留，必答 / 限选照常按规则识别
- 重复试题：打开核对区（GET …/imports/{fileId}）时实时比对，不加新列。只标还没核对的题，标了的置信度显示为低：
  - 同一年份下题干相同（内容哈希），或同题型且题干互相重合 90% 以上算重复，与用户端规则一致；有一方不知道年份时按同一年算
  - 比对范围：已发布的官方题（下线的除外）、未发布未退回的新增题目草稿、项目里各份资料还没驳回的解析题
  - 两道都还没核对时只标排在后面的（后传的资料、同一份里题号靠后的），不会互相标
  - 不同年份考了同一题不算重复，返回 seen_years 提示「某年也考过」
- POST …/imports/{fileId}/reject-duplicates：一键驳回这份资料里标为重复的题，返回驳回条数；别人刚核对过的跳过
- 提示词与模型不变，不需要重跑评测

## 范围 · 管理后台（peetraining-admin）

- 上传框接受 .md / .markdown；md 与 CSV 一样读成文字直接提交，不传 OSS
- 真题卷上传前：本项目已有同一年份的真题卷（解析失败的不算）时弹窗提醒「这一年的真题已经传过」，列出已有的文件与题数，可以继续上传
- 核对区：重复题列表里标红色「重复」，右侧写明和谁重复；「驳回重复题（N 题）」一键驳回；别的年份考过的提示「2019、2023 年也考过这道题」

## 验收

- [x] 上传 .md 文件（带 BOM 也行）解析出与纯文字相同的题，原文与题干里没有 #、**、>、---、链接网址；限选分组照样识别
- [x] 粘贴 Markdown 文字同样去掉排版标记
- [x] 同一年份再传一次：后传的逐题标「与《2025 真题.md》第 N 题相同」、置信度低；先传的不标
- [x] 一键驳回重复题；再点没有可驳回的；跨项目 404
- [x] 别的年份考了同一题：不算重复，seen_years 列出年份
- [x] 已接受（进了草稿）的题、同一份资料里的同一题都能认出来
