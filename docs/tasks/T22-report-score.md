# T22 整卷报告、时间分析、预估分与提分看板

- 仓库：后端 + 前端（先后端，后前端）
- 依赖：T21
- 计划完成：10/11
- 状态：审查中（真机待测）

## 目标

做完真题卷后，用户能看到分数、时间问题和离目标多远。

## 范围 · 后端部分（在 peetraining-server 里做，先合并并打契约标签）

- 整卷报告：总分、较上次、与目标差距、题型得分、失分归因三类、是否计入预估分
- 时间分析：建议与实际用时、超时、未答、估计时间失分、下次分配建议、趋势
- 预估分按 11.6 计算并在交卷、删除资料、改采分点后重算；首页与看板接口

## 范围 · 前端部分（在 peetraining-web 里做，先执行 pnpm gen:api）

- 4.24 整卷报告、4.25 时间分析报告、2.1 预估分卡、6.2 提分看板
