# T11 作文资料整理

- 仓库：后端（peetraining-server）
- 依赖：T09
- 计划完成：10/9
- 状态：审查中（真实样本测试留到最后统一做）

## 目标

把作文真题、评分细则、范文和写作笔记整理成作文知识库。

## 范围

- 资料类型判断：每份资料归为题目类、参考类或作文类；专业课的资料以作文类为主时按作文课处理（PRD v3 11.12），结果在 1.7 可改
- 作文真题识别（题目、年份、要求字数）
- 评分细则识别：维度、说明、分值、分档；没有时提供通用五维度标准
- 写作方法归纳（标出处页码）、素材整理（按主题，AI 补充的单独标）、范文归类与结构拆解
- 以上都写进待确认，与题目导入共用确认流程

## 参考

- docs/prd.md 第 9 节模块 5、第 11.13 节
- docs/design/pages/m3_essaykb、m5_rubric、m5_material、m5_model

## 验收

- 用 2 份作文资料样本跑通，评分标准、写作方法、素材、范文都能在接口里取到并带出处

## 不做

- 卡片范围以外的页面、接口和重构；发现需要的，记到 docs/open-questions.md

## 记录（开发中填写）

- 实现要点：
  - 资料类型判断 material_classify（廉价模型）：每份资料在结构化前按文件名和前 3 页归为题目类 / 参考类 / 作文类及细分类型，写入 materials.category、sub_type；判断失败时按 1.4 选的方式处理
  - 作文类资料不论 1.4 选什么都走作文资料整理 essay_organize：作文真题（题目、年份、要求字数）、评分细则（维度、说明、分值、分档）、写作方法（对应评分维度、出处页）、素材（按主题，AI 补充的单独标）、范文（正文逐字摘录 + 结构拆解）；校验：题目与范文必须能在原文逐字找到、非 AI 补充的素材来自原文、维度分值合计等于满分
  - 作文条目与题目共用待确认与确认流程；确认入库：作文题 → questions（qtype=essay，记要求字数）、评分细则 → essay_rubrics（设为当前标准，旧的停用）、写作方法、素材、范文（按作文题归类）
  - 作文课判断：每次整理后按这门课已解析资料的类型更新 subjects.is_essay（作文类过半），essay_set_by=user 后不再自动改；导入任务返回 detected_essay
  - 迁移 00010：questions.required_words
- 偏离计划的地方与原因：
  - 没有评分细则时的「通用五维度标准」已在 T03 的种子数据里（essay_rubrics.source=generic），批改时取用，在 T23 做
- 需要手动验证的步骤（最后统一做）：
  - 用 2 份真实作文资料（如 908 真题 + 评分细则、写作笔记 + 范文）跑真实模型，在 1.7 核对各类条目与出处
- 验收结果：
  - [x] mock 下作文资料跑通：评分标准、写作方法、素材、范文、作文题都能在待确认接口取到并带出处（文件 + 页码），确认后入库（TestEssayImport）
  - [ ] 2 份真实样本：等网络与样本
