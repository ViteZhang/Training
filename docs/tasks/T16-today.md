# T16 今日：计划生成与首页

- 仓库：后端 + 前端（先后端，后前端）
- 依赖：T13、T15
- 计划完成：10/10
- 状态：审查中

## 目标

每天 0 点生成计划，首页回答离目标多远、今天练什么。

## 范围 · 后端部分（在 peetraining-server 里做，先合并并打契约标签）

- 每日 0 点（北京时间）生成今日计划的定时任务（Asynq 调度器只启一个），新用户确认入库后立即生成
- 首页聚合接口：倒计时、阶段、预估分卡数据（T22 前返回空）、今日计划、阶段主推、我的题库统计、以为会了
- 阶段切换提示；今日训练完成统计

## 范围 · 前端部分（在 peetraining-web 里做，先执行 pnpm gen:api）

- 2.1 今日首页（正常）、2.1d 今日已完成、2.1e 进入新阶段提示、2.1f 修改目标分、2.2 今日训练完成

## 记录（开发中填写）

- 实现要点：
  - 契约 v0.3.0（只加不改）：getHome、answerStagePrompt、getTodayPlan、getTodaySummary
  - plan 包：按 PRD 11.5 为每门课准备候选（到期复习＝错题本到期或知识点复习日已到；新知识点＝基础期未学；薄弱查漏＝强化期以后的未学与未掌握；背诵＝未背或背诵到期），提分收益与单题用时取 rules；按阶段构成（MixFor，冲刺期覆盖率不足保留新知识点）用 BuildPlan 填满每日分钟数；结果存 daily_plans 快照
  - 当天幂等：同一天再取不重排；已经开始做（当天有作答或背诵）后，题库变化也不重排；做过的题和背过的知识点标为完成，全部做完写 completed_at
  - 新用户确认入库后立即生成（importer.AfterConfirm → plan.Regenerate）；每天 0 点（北京时间）plan:daily 定时任务给所有用户生成，单个用户出错不影响其他人，重跑不重复生成；用户当天首次打开首页也会补生成
  - 首页聚合：状态（还没导入资料 → 题库整理中 → 今日已完成 → 正常）、倒计时与阶段、今日计划与分组统计、阶段主推（基础期新知识点进度、强化期本周题型专项＝真题里分值最高的题型、冲刺期本周整卷、考前期模拟考试）、我的题库（题数、知识点数、掌握分布、整理中已识别条数）、以为会了（自评掌握且近 7 天实测正确率低）、连续打卡、明天预计用时；预估分卡在 T22 前返回空
  - 阶段提示（PRD 11.4）：按日期到点或强化期提前进入冲刺期时提示，同一目标阶段只弹一次；接受立即切换并重排今天的计划，拒绝留在当前阶段
  - 今日完成统计：题数、正确率（主观题按得分率阈值）、用时、新增已掌握、主观题失分归因占比
  - App：2.1 正常首页、2.1b / 2.1c 改由首页接口的状态驱动、2.1d 今日已完成、2.1e 进入新阶段提示（构成对比）、2.1f 修改目标分（弹层，复用 1.2 的加减器）、2.2 今日训练完成（/plan/summary）
- 偏离计划的地方与原因：
  - 预估分卡只显示目标分与「做完一套整卷后生成预估分」，分数、差距、「今天 +2 分」在 T22 接通
  - 2.2 掌握度变化先只显示新增已掌握的数量；逐条的状态变化（mastery_changes）需要掌握度变化记录，在 T17 / T18 写作答与批改时补上，现在返回空数组
  - 设计稿首页底部的「背诵 · 错题本 · 整卷」快捷入口依赖 T17、T20、T21 的数据，到对应卡片再加
  - 「开始训练」「去练」「再练一组」先进入训练 Tab，按计划逐题练在 T17 接通
- 需要手动验证的步骤：
