# T54 后台：项目工作台（11 月 6 日产品确认）

- 仓库：管理后台（云效 peetraining-admin）为主；后端视需要补接口
- 依赖：T55
- 状态：开发完成

## 背景

后台官方题库相关的页按 PRD 编号排，导入、录题、关联资料分在几页，彼此依赖却不提示先后顺序（808 导入时项目没关联教材，答案全按通用知识生成）。

## 已确认的方案

- 菜单：官方资料库、官方题库、审核队列、版本发布（另有申请收录、需求洞察、通用体验题）；去掉「AI 解析导入」（7.17）与「内容生产」（7.12）
- 官方题库点进一个项目就是工作台，按顺序：
  1. 关联资料：从资料库选教材、讲义、考纲、经验总结；没有的可在这里直接上传，传完自动关联
  2. 知识框架：按已关联的考纲或参考书目录一键生成（不用再传一次）
  3. 导入真题：真题卷 AI 解析、表格导入（原 7.17；去掉「讲义」类型）
  4. 核对：原 7.17 核对区
  5. 手动录题：原 7.12 内容生产
  6. 审核与发布：显示待审核、可发布数量，点进 7.13 / 7.14
- 每一步显示状态（如「已关联 0 本，未完成」「待核对 63 题」）与下一步按钮

## 实现计划（2026-11-06，产品要求定完计划直接实施）

工作台合成五步（导入真题与核对放在一起：核对区本来就挨着资料列表）：

1. 关联资料：项目关联的资料（标类型、能否检索）；内容负责人可以关联已有资料，或在这里直接新建资料并完成导入、校对、建索引、发布（复用资料库的弹窗），发布后一键关联
2. 知识框架：列出已关联的考纲、教材、讲义，点「生成知识框架」——考纲按全文、教材讲义按章节目录生成知识点，结果进核对区；资料库里没有的仍可上传参考书目录
3. 导入真题与核对：原 7.17 的资料列表与核对区；上传类型只留真题卷、表格（讲义放资料库，参考书目录放第 2 步）
4. 手动录题：原 7.12（拆知识点、官方题库、我的草稿、录题、新建知识点）
5. 审核与发布：本项目待审核条数、当前版本；内容负责人点进审核队列、版本发布

每步在顶部步骤条显示状态与是否完成；项目设置（阶段、编辑、授权资料清单）放在工作台右上角「项目设置」。

### 后端

- POST /admin/official/projects/{projectId}/framework {edition_id}：用已关联资料的当前发布原文生成知识框架（新建一份「参考书目录」解析记录，走原来的知识点候选与核对）；
  考纲用全文，教材、讲义只用章节标题；经验总结不能生成（400）；没关联、没发布原文的 404 / 400；内容负责人、内容编辑可用（编辑限分配的项目）

### 后台

- 新页 /official/:projectId；7.11 列表点项目进入工作台；菜单去掉「AI 解析导入」「内容生产」，旧地址跳到官方题库
- 内容编辑也能看到「官方题库」（只看到分配的项目，不能新建项目、改设置、关联资料）
