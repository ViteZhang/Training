# T17 练习、客观题与错题本

- 仓库：后端 + 前端（先后端，后前端）
- 依赖：T13、T15
- 计划完成：10/10
- 状态：审查中

## 目标

用户能连续刷今日训练和自定义练习，作答立即影响掌握度和复习。

## 范围 · 后端部分（在 peetraining-server 里做，先合并并打契约标签）

- 练习会话：今日训练、题型专项、自定义练习（范围、题型、题量、只练未掌握、AI 补题开关）、错题重做
- 客观题判分、看答案、自评；作答写 attempts 并按规则更新 kp_mastery、复习日、错题本
- 当天题目预下载（含客观题答案），联网后服务端复核离线作答
- 本组总结；错题本分组与移出；退出保存进度
- 1.8 可选摸底测：从题库抽 20 题组成一个练习会话，可跳过；按对应题型事件更新掌握分（PRD v3 11.1）
- AI 题报错：同一道题被报错 3 次自动下线

## 范围 · 前端部分（在 peetraining-web 里做，先执行 pnpm gen:api）

- 4.1 训练首页、4.2 自定义练习、4.3 客观题、4.10 退出训练确认、4.11 本组训练总结、4.12 错题本
- 接通 1.8「先做个摸底测」入口（页面在 T12 做）
- 离线作答与恢复

## 参考

- docs/prd.md 第 8 节、第 11.1–11.3 节、第 11.8 节
- docs/design/pages/m4_practice、m4_setup、m4_answer、m4_exit、m4_summary、m4_wrong

## 验收

- 飞行模式下能继续做当天的客观题，恢复网络后自动提交并复核
- 答错后错题本出现，两个不同日期答对后自动移出（集成测试用时间模拟）

## 不做

- 卡片范围以外的页面、接口和重构；发现需要的，记到 docs/open-questions.md

## 记录（开发中填写）

- 实现要点：
  - 契约 v0.4.0（只加不改）：getPracticeHome、previewPractice、createPracticeSession、getPracticeSession、savePracticeProgress、submitAttempt、finishPracticeSession、getWrongBook、removeFromWrongBook、reportQuestion
  - 练习会话：今日训练（取今日计划里这门课的题并带分组，当天复用同一个会话）、题型专项、自定义（板块含子章节、题型、题量、只练未掌握、AI 补题）、错题重做（全部或按知识点 / 题型 / 失分原因一组，按下次复习日升序）、摸底测（按题型轮流取、尽量覆盖不同知识点，最多 20 题）
  - 作答：客观题服务端判分（单选、多选按选项集合，判断题接受选项字母或对 / 错，填空去掉空白标点逐空比较）；看答案、主观题自评；幂等键防重复；离线作答补交时按客户端作答时间（7 天内、不晚于服务器时间）记，服务端复核，写 verified_at
  - practice.Apply 统一更新学习状态（T18 批改、T21 整卷复用）：先补逾期衰减，再按事件改 M（主知识点全额、其余减半），答对日期、状态、复习日（PRD 11.1–11.3）；错题本收录、连续两个不同日期答对自动移出（已消灭）、答错清零（PRD 11.8）
  - 新 AI 能力 question_variant（便宜档）：题库不够时按有资料原文和出处的知识点出变式题，标 AI 出题、记录依据的知识点与资料页，每题扣 1 次 AI 出题额度；额度用完或出题失败就少出，不报错
  - 「题目有问题」：每次报错计数，AI 出的题累计 3 次自动下线，之后不再出现在练习里
  - 本组总结：完成题数、正确率（按判了对错的题）、用时、按题型、来自题库 / AI 的题数、需要再看的知识点（最多 3 个，附原因）、一句只描述数据的总结
  - App：4.1 训练首页（专业课切换、今日训练、本周题型专项、按题型练、继续上次、错题本，冲刺期以后整卷置顶）、4.2 自定义练习（服务端实时预览题数与用时）、4.3 答题（选中即判分、多选与填空提交、看答案、报错、AI 出题来源）、4.10 退出确认、4.11 本组总结、4.12 错题本（三种分组、按组重做、重做全部）、1.8 摸底测入口
  - 离线：会话（含客观题答案）缓存在本地，断网时继续做、本地判分（与服务端同一套规则）；作答进待提交队列，下次提交前、进训练页、App 回到前台时按顺序补交（offline=true），以服务端复核结果为准
- 偏离计划的地方与原因：
  - 主观题在练习里先提供「看参考答案 → 自评」，打字作答与 AI 批改是 T18 的范围
  - 本组总结的一句话用模板按数据生成，不调模型：PRD 要求「只描述数据」，模板更稳、不花额度
  - 整卷、背诵、答题规范入口先提示「马上上线」，分别在 T21、T20 与后续卡片接通
  - question_variant 还没有评测集（make eval 只有 import 与 kp），等真实模型接入时与 T31 一起补样本和门槛
- 需要手动验证的步骤：
  - 真机飞行模式：开始一组客观题 → 开飞行模式继续作答 → 关飞行模式回到前台，确认自动补交、错题本与掌握分更新
  - 真实模型下 AI 补题的题目质量（出处、答案是否在选项里）
- 验收结果：

  - [x] 答错后错题本出现，两个不同日期答对后自动移出（TestObjectiveWrongBookAndMastery，用可拨的时钟模拟跨天）
