# T13 题库：知识点、题目、资料

- 仓库：后端 + 前端（先后端，后前端）
- 依赖：T10
- 计划完成：10/9
- 状态：审查中

## 目标

用户看得到、管得了自己导入的知识点、题目和资料。

## 范围 · 后端部分（在 peetraining-server 里做，先合并并打契约标签）

- 知识点树、题目列表（按题型、来源、章节筛选与排序）、资料列表的查询接口
- 知识点卡片：原文、出处、采分点、AI 解读（首次生成后缓存）、相关题目、自评
- 编辑知识点（名称、原文、采分点、归属）、调整归属、合并、拆分、删除、重新生成 AI 解读
- 题目详情与编辑；我的作答记录
- 搜索：当前专业课内的知识点、题目、资料原文
- 原文查看：按资料分页返回识别文字与出处定位

## 范围 · 前端部分（在 peetraining-web 里做，先执行 pnpm gen:api）

- 3.1 知识点、3.1b 题目、3.1c 资料、3.1d 删除资料确认
- 3.2 搜索、3.3 题目详情、3.4 知识点卡片、3.5 更多操作、3.6 编辑知识点、3.7 原文查看
- 6.3 我的资料

## 记录（开发中填写）

- 实现要点：
  - 后端 internal/bank：题库概况（题数、知识点数、待核对、资料数、真题卷数、掌握状态分布、是否作文课）；知识点树（全部 / 未掌握 / 真题考过 / 待核对，筛选只作用在知识点上，板块平均掌握度与「短板」按 rules.SectionMastery）
  - 知识点卡片：路径、原文、出处（优先知识点记录的那一处）、掌握度、采分点与来源、相关题目（最多 20）、AI 解读（kp_explain，第一次打开同步生成并缓存，失败不影响卡片）
  - 编辑知识点（名称、原文、采分点、归属、核对完成），内容改了 AI 解读作废；新建节点与调整归属有层级校验（板块无上级、章节在板块下、知识点在板块或章节下、不能移到自己下面）；合并（题目关联、出处、下级、采分点、掌握度迁到目标）；拆分（新知识点都关联原题与出处）；删除（题目保留）；重新生成解读；三档自评（没有作答时设 M，有作答时只记录，D16）
  - 题目列表：题型、来源、年份、知识点（含下级）、状态筛选，按章节或最近做过排序，分页，各题型 / 来源题数与真题年份；状态：待核对 > 错题 > 已掌握 > 还没做过 > 已做过
  - 题目详情：参考答案与来源、出处、采分点与来源、知识点、每次作答（得分、遗漏的采分点、失分类型）、是否在错题本；手动加题计入导入题数；编辑题目时采分点合计须等于分值，改采分点 rubric_version 加 1，历史批改与快照不变；删除题目连同作答与错题
  - 原文查看：忽略空白定位高亮、低置信度位置、本页知识点；搜索：知识点名称与原文、题干、资料原文，命中片段前后 30 字并给高亮位置，LIKE 通配符转义
  - App：题库页（专业课切换、知识点 / 题目 / 资料分栏、待核对提醒条、搜索入口、导入）、3.1 知识点树（板块折叠）、3.1b 题目（题型带数量、来源、排序、分页）、3.1c 资料与解析额度条、3.1d 删除说明连带影响、3.2 搜索（三组结果、高亮、最近搜索）、3.3 题目详情与编辑、3.4 知识点卡片（关键词下划线、自评）、3.5 更多操作（编辑、调整归属、合并、拆分、重新生成、删除）、3.6 编辑知识点、3.7 原文查看（上一页 / 下一页）、6.3 我的资料（「我的」入口）
