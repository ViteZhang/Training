# T17 练习、客观题与错题本

- 仓库：后端 + 前端（先后端，后前端）
- 依赖：T13、T15
- 计划完成：10/10
- 状态：未开始

## 目标

用户能连续刷今日训练和自定义练习，作答立即影响掌握度和复习。

## 范围 · 后端部分（在 peetraining-server 里做，先合并并打契约标签）

- 练习会话：今日训练、题型专项、自定义练习（范围、题型、题量、只练未掌握、AI 补题开关）、错题重做
- 客观题判分、看答案、自评；作答写 attempts 并按规则更新 kp_mastery、复习日、错题本
- 当天题目预下载（含客观题答案），联网后服务端复核离线作答
- 本组总结；错题本分组与移出；退出保存进度
- AI 题报错：同一道题被报错 3 次自动下线

## 范围 · 前端部分（在 peetraining-web 里做，先执行 pnpm gen:api）

- 4.1 训练首页、4.2 自定义练习、4.3 客观题、4.10 退出训练确认、4.11 本组训练总结、4.12 错题本
- 离线作答与恢复

- 飞行模式下能继续做当天的客观题，恢复网络后自动提交并复核
- 答错后错题本出现，两个不同日期答对后自动移出（集成测试用时间模拟）
