# T06 账号：登录、协议、设备与注销

- 仓库：后端 + 前端（先后端，后前端）
- 依赖：T03
- 计划完成：10/7
- 状态：未开始

## 目标

用户能用手机号登录，协议、权限、版本更新、注销都按 PRD 走。

## 范围 · 后端部分（在 peetraining-server 里做，先合并并打契约标签）

- 短信验证码：6 位、5 分钟有效、60 秒一次、每天 10 次、错 5 次失效（Redis 计数）
- 登录即注册；访问令牌 + 按设备的刷新令牌；设备列表与移除
- 协议版本：后台配置正文与版本，记录用户同意的版本，有新版本时启动接口返回需重新同意
- 版本检查接口：最新版本、最低版本、下载地址
- 注销：申请后 7 天冷静期，期间登录即撤销；到期由定时任务删除账号、资料原件（含 OSS）、题目与作答
- 更换手机号（新旧号码都验证）

## 范围 · 前端部分（在 peetraining-web 里做，先执行 pnpm gen:api）

- 模块 0 全部 13 页：0.1–0.6b（设计稿 m0_*）
- 6.11 账号与安全、6.12 注销账号
- 短信自动填充；权限说明弹层只在首次使用对应功能时出现

## 验收

- 真机走通：输入手机号 → 收验证码 → 登录 → 新用户进 1.1，老用户进 2.1
- 验证码错误、过期、频率限制、协议未勾选、协议更新、强制更新各状态与设计稿一致
- 注销后 7 天内登录可撤销；到期后数据库与 OSS 中该用户内容全部删除（集成测试覆盖）
