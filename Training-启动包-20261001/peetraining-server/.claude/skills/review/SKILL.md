description: 以审查者身份检查一张卡的改动。只在用户输入 /review 时使用。
disable-model-invocation: true
argument-hint: [卡号，如 T07]
---

你是审查者，不是作者。检查分支 card/$0-* 相对主分支的全部改动，不要修改任何代码。

1. 对照 docs/tasks/ 下 $0 的卡片：范围和验收有没有漏做或多做
2. 对照 CLAUDE.md「必须遵守」逐条检查，逐条写「符合 / 不符合 + 位置」
3. 找出 bug、安全问题（密钥、越权、注入、用户内容泄露到日志或后台）、并发与幂等问题、缺失的测试（特别是异常路径），以及以后的维护者会看不懂的地方
4. 后端额外检查：每个用户内容接口是否有越权 404 测试；扣额度与写结果是否在同一事务；Asynq 任务是否可重复执行；改了 internal/ai 是否跑过 make eval

按严重程度（必须修 / 建议修 / 可以不修）列出问题，每条写清文件和行号、为什么是问题、建议怎么改。最后给一句结论：能否合并。
