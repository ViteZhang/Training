# 协议草稿（T32）

这里是用户协议、隐私政策、会员服务协议的**草稿**，按 PRD v3 第 16 节与 dev-spec 第九节列出的必备内容写成，**须经法务审核定稿**后才能发布。
【】里的内容（运营主体、联系方式、备案号等）由你填写。

定稿后在后台 7.8「协议」新建版本（kind：user / privacy / membership，版本号如 1.0），粘贴正文，确认生效时间后发布。
发布后新用户在 0.4 看到；以后再发新版本，老用户下次打开 App 时在 0.4b 重新同意，消息中心同时收到「协议更新」。

| 文件 | 协议 | 必备内容（PRD 16.3、dev-spec 九） |
| --- | --- | --- |
| user-agreement.md | 用户协议 | 上传声明（有权上传、不侵权）、AI 内容仅供参考与标识、预估分不代表实际成绩、侵权投诉与删除渠道、注销 |
| privacy-policy.md | 隐私政策 | 资料仅本人可见、不用于训练模型、存储在境内、后台默认看不到；授权查看 72 小时与通知；第三方服务清单；注销 7 天冷静期 |
| membership.md | 会员服务协议 | 一次性购买不自动续费、时长叠加、退款规则（13.3，PRD 17 待法务确认）、兑换码与邀请奖励 |

需要你另外确认的事项：
- 模型服务商关于「客户数据是否用于训练」的条款核对结果（dev-spec 九「不用于训练」），记进 docs/adr
- 生成式 AI 登记、模型名称与备案号公示的时间（PRD 16.3）
