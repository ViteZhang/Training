# 协议正文（v1.0）

用户服务协议、隐私政策、会员服务协议的正文，运营主体为北京筑梦探索科技有限公司（2026-10-25 定稿版）。
每个文件就是后台 7.8「协议」里要粘贴的正文（不含标题和日期行，App 0.4 页头会显示版本号、更新日期、生效日期）。

| 文件 | kind | 标题 |
| --- | --- | --- |
| user-agreement.md | user | 用户服务协议 |
| privacy-policy.md | privacy | 隐私政策 |
| membership.md | membership | 会员服务协议 |

## 发布

1. 后台 7.8「协议」新建版本（kind 见上表，版本号 1.0；已发布过旧版本就递增，如 1.1），粘贴正文，选生效时间后发布
2. 新用户在 0.4 看到新正文；老用户下次打开 App 时在 0.4b 重新同意（弹窗里显示「变更摘要」），消息中心同时收到「协议更新」

## 排版（App 0.4 支持的写法）

- `### 标题`、`**加粗**`（可在段落中间）、`1. ` 和 `- ` 列表、Markdown 表格
- 段落之间空一行

## 上线前要核对的事项

1. 隐私政策附录二的第三方清单要与 App 实际集成的一致。目前 App 没有接入极光 / 个推推送和微信开放平台 SDK（学习提醒用的是本地通知），这两行标着「如启用」，没接入就删掉；火山方舟同理（当前备用模型是百炼）
2. 若用 Expo EAS Update 下发热更新，更新包从境外服务器下载，需改为自建更新服务或在隐私政策里补充说明
3. AI 生成内容在页面上标注来源；向北京网信办确认是否需要办理大模型应用登记
4. 支付开关打开前，确认会员价格、退款规则与用户协议第七条、会员服务协议一致
5. 本稿不是法律意见，正式发布前建议请律师过一遍
