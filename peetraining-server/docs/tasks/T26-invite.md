## 记录（开发中填写）

- 实现要点：
  - internal/invite：注册时在创建账号的事务里绑定邀请关系（auth.Deps.OnRegister）；被邀请人第一次确认导入资料时在同一事务里激活（importer.OnConfirmedTx），锁邀请行与邀请人行，奖励只发一次、累计不超过上限
  - 奖励天数与上限读 rule_params.growth（invite_days 7、invite_max_days 70）；以 gift 会员叠加到当前会员之后，双方各收到一条消息
  - 契约 api-v0.13：GET /me/invites（受 invite 开关控制，关闭 404）；LoginRequest.invite_code 原有字段开始生效
  - 前端：6.8 邀请研友（邀请码、复制、生成海报并分享、系统分享、邀请记录与已获得天数）；我的页入口与登录页邀请码输入框只在开关打开时显示，邀请链接 ?invite= 自动填入
  - 新增依赖：expo-clipboard（复制邀请码）、react-native-view-shot（把海报截成图片分享），都是 Expo SDK 支持的常用库
- 偏离计划的地方与原因：
  - 「分享给微信好友」用系统分享面板（选微信），不接微信开放平台 SDK（D35）
- 需要手动验证的步骤：
  - 真机：对自己的账号打开 invite 开关，复制邀请码、生成海报并分享到微信
  - 新手机号在登录页填邀请码注册，导入第一份资料后双方「我的」会员有效期各延长 7 天，并收到消息
