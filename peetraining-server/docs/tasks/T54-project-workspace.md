# T54 后台：项目工作台（11 月 6 日产品确认）

- 仓库：管理后台（云效 peetraining-admin）为主；后端视需要补接口
- 依赖：T55
- 状态：待开发

## 背景

后台官方题库相关的页按 PRD 编号排，导入、录题、关联资料分在几页，彼此依赖却不提示先后顺序（808 导入时项目没关联教材，答案全按通用知识生成）。

## 已确认的方案

- 菜单：官方资料库、官方题库、审核队列、版本发布（另有申请收录、需求洞察、通用体验题）；去掉「AI 解析导入」（7.17）与「内容生产」（7.12）
- 官方题库点进一个项目就是工作台，按顺序：
  1. 关联资料：从资料库选教材、讲义、考纲、经验总结；没有的可在这里直接上传，传完自动关联
  2. 知识框架：按已关联的考纲或参考书目录一键生成（不用再传一次）
  3. 导入真题：真题卷 AI 解析、表格导入（原 7.17；去掉「讲义」类型）
  4. 核对：原 7.17 核对区
  5. 手动录题：原 7.12 内容生产
  6. 审核与发布：显示待审核、可发布数量，点进 7.13 / 7.14
- 每一步显示状态（如「已关联 0 本，未完成」「待核对 63 题」）与下一步按钮

开工前另出实现计划确认。
