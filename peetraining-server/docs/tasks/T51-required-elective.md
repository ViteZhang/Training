# T51 官方题库必答 / 限选：按专业分组的题，按报考方向复制（11 月 6 日产品更新）

- 仓库：后端 + App（peetraining-web）+ 管理后台（云效 peetraining-admin）
- 依赖：T30、T47、T50
- 状态：开发完成（后台页面待 peetraining-admin）

## 背景

北师大 808 中国语言文学 2025：名词解释、简答所有考生都答；论述题分七组，「请选择文艺学、比较文学与世界文学专业的考生作答」，
回答非报考专业不得分。用户自己导入的真题已经能识别分组、按报考方向只保留一组（迁移 00020），
但官方题库的录题、7.17 解析、发布、复制到用户题库都没带分组，做成官方题库后七组论述题会全部给每个用户。
需求见 [official-first.md「必答与限选」](../features/official-first.md)。

## 范围 · 后端

- 官方题 payload 加 group（{ label, majors }）：有是限选题，没有是必答题；7.12 草稿校验组名（32 字以内）
- 7.17 真题卷解析：规则识别的分组带进草稿；表格导入加「限选分组」「适用专业」两列（只填适用专业时报错）
- 发布写 questions.group_label / group_majors；内容哈希只在限选题时多算分组，必答题与已同步副本的哈希不变
- 复制到用户题库（11.15 同步）：副本带上分组；限选题只复制与这门课报考方向（subjects.my_majors）匹配的组，
  同一年一组都对不上时全部保留，没填方向时全部保留；不匹配的已有副本下线（作答记录保留），匹配时恢复
- 1.1 选填的报考专业记为报考方向（已有方向的不覆盖）
- 改报考方向后重新对：PATCH /subjects/{id} 改 my_majors、导入核对页选方向（POST /import-jobs/{id}/groups）之后
- 不需要新迁移（questions 的分组列在 00020 已有）；提示词与模型不变，不需要重跑评测

## 范围 · App

- 限选题标签「限选 · 第一组」，详情说明「限选题（第一组）：……专业的考生作答，回答非报考专业不得分」
- 整卷作答：卷子里有限选题时，其余题标「必答」

## 范围 · 管理后台（peetraining-admin，另行开发）

- 7.12 题目编辑：「必答 / 限选」切换，限选时填组名与适用专业（写 payload.group）
- 7.17 核对区：显示限选标签，可修改；表格导入模板加「限选分组」「适用专业」两列
