# T55 官方资料库：考纲与经验总结（11 月 6 日产品确认）

- 仓库：后端 + 管理后台（云效 peetraining-admin）；App 不改（只同步接口契约副本）
- 依赖：T40、T53；决定见 open-questions Q20
- 状态：开发完成

## 背景

北师大等学校不指定参考书、只有考纲；有的科目有上岸学长学姐的经验总结。资料库原来只有教材、讲义两类，
考纲、经验总结没有地方放，生成答案时也用不上。

需求见 [official-first.md「资料库：考纲与经验总结」](../features/official-first.md)。

## 范围 · 后端

- 资料类型加 syllabus（考纲）、experience（经验总结）；textbooks.kind 本来是文字列，不改库
- 经验总结建书、加版本时自动记为已获授权（没写授权说明时用「经验总结：上传即视为已获授权」）；其他类型仍要授权
- 生成答案的检索按类型分名额：教材讲义最多 10 段，考纲、经验总结各最多 3 段；片段带资料类型（EvidenceFragment.material）
- 提示词：answer_generate v4（各类资料的分工与优先级；关键词只取答案原文的知识内容；引用的观点只复制一句原文）、
  answer_evidence_select v2（按类型判断是否有用，覆盖判断只看教材讲义）、answer_citation_check v2（按类型核验引用）；
  挑选结果的校验改为「选了教材讲义不能是 none，只选了考纲、经验总结必须是 none」
- 「没有引用教材」（T53）只看教材、讲义；只关联了考纲、经验总结的项目记 no_textbook，考纲、经验总结照样用
- 引用（OfficialImportItem.citations、7.12 候选的快照）带 material
- 考生端：按书名匹配参考书只认教材、讲义；考生的答案只检索教材、讲义；VisibleSnapshot 去掉考纲、经验总结来源

## 范围 · 管理后台

- 「官方教材库」改名「官方资料库」；类型四种，可按类型筛选；新建经验总结时不显示授权项
- 项目「关联教材」改为「关联资料」，标类型
- 核对区、7.12 的引用标「考纲」「经验总结」

## 不做

- 考点覆盖分析（考纲里哪些考点真题没考过）
- 知识框架直接从已关联的考纲生成、项目工作台：T54

## 验收

- [x] 资料库能建四种类型；经验总结不勾授权也能建，自动记为已获授权；考纲不授权 400；不认识的类型 400
- [x] 项目关联教材、考纲、经验总结后生成答案：三类都取到段落并标明类型，考纲、经验总结各不超过 3 段
- [x] 只关联考纲、经验总结：照样用，原因记 no_textbook；只引用考纲时仍提示没有引用教材
- [x] 考生填书名匹配不到考纲；考生看到的出处去掉考纲、经验总结
- [x] 提示词虚构示例评测（evals/README.md 2026-11-06）
- [x] 后台测试
