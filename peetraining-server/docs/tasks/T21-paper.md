# T21 整卷与模拟考试

- 仓库：后端 + 前端（先后端，后前端）
- 依赖：T18
- 计划完成：10/11
- 状态：未开始

## 目标

用户能用导入的真题卷或 AI 组卷做整卷练习和模拟考试。

## 范围 · 后端部分（在 peetraining-server 里做，先合并并打契约标签）

- 真题卷列表（含缺题卷按实际满分计分说明）；AI 组卷（标准卷、针对卷，11.10），不够时补变式题并标出
- 同一时间只能一套进行中；练习模式可暂停；模拟考试服务端 deadline_at，离开继续计时，10 分钟内可恢复一次
- 每题用时记录；时间提醒点按 11.9 计算
- 交卷：客观题即时出分，主观题 Worker 异步批改（约 2 分钟），完成发消息；整卷批改额度每周 1 套

## 范围 · 前端部分（在 peetraining-web 里做，先执行 pnpm gen:api）

- 4.18 整卷列表、4.19 选择作答模式、4.20 练习模式、4.21 模拟考试、4.22 答题卡、4.23 交卷确认
