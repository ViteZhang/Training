# T57 官方真题进真题卷、计入考频、参与估分（11 月 10 日产品确认）

- 仓库：后端（App、管理后台不改）
- 依赖：T21（整卷）、T30（官方题库）、T56
- 迁移：无
- 状态：开发完成

## 背景

官方题库添加到用户题库后，题目的来源是 official，而真题卷、知识点考频、考情分析只认用户自己导入的真题（source = exam）。
结果是：用户添加了官方题库，「整卷」里看不到任何一年的真题卷，官方真题也不计考频，按真题卷估分用不上官方题。
PRD 11.15 写的是「刷题、批改、复习只认结构，不区分来源」「添加了官方题库的课程，考情分析和组卷优先用官方的命题画像」。

## 范围

- 真题：官方题库里有年份的题（source = official、exam_year 不为空）与用户自己导入的真题一样算真题
- 同一年用户自己也导入过真题时只用官方的（编辑审核过、题目完整），免得同一年的题算两遍：
  - 组真题卷（ListExamQuestionsByYear）
  - 知识点考频（RecountKPExamCounts）
  - 考情分析、AI 组卷的命题画像（ListBankExamQuestions）
- 真题卷的有效性检查（列表、详情、题目、最近一套）收官方真题；AI 组卷的「整卷里做过」也算官方真题卷
- 添加、同步（每次发布、回滚、改报考方向）、移除官方题库后，重组涉及年份的真题卷、重算考频：
  - 添加或同步后，官方真题按年份组卷，限选题按报考方向只取一组（与导入组卷规则相同）
  - 移除后，那几年改回用户自己导入的真题；没有自己的真题时卷子清空（列表里不再显示）
- 移除官方题库时用户改过、留下来的官方真题变成用户自己的真题（以前变成习题）
- 估分不用改：真题卷（real_exam）的整卷成绩本来就参与估分，官方真题能组卷就能参与

## 不做

- 题库列表「历年真题」筛选：官方题在「官方」里看（T48）
- 官方模拟卷（D40）
