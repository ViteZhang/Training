# T34 参考教材（PRD 10 月 26 日更新）

- 仓库：后端 + 前端
- 依赖：T07、T08
- 计划完成：10/27
- 状态：开发完成（生产待验证）

## 目标

用户给每门专业课填指定教材（选填），资料里缺答案时，AI 生成参考答案贴近教材表述（生成时使用见 T35）。

## 范围

- 后端：迁移 00023 subjects.textbooks（JSON 书名列表）；PATCH /subjects/{id} 的 textbooks 整体替换，去掉空白与重复，最多 5 本、每本 64 字；Subject 返回 textbooks
- 前端：1.3 备考安排「参考教材」列表与「添加教材」（多门课时选专业课）；6.9 备考设置每门课一行摘要，点开编辑

## 验收

- 去重、上限、清空、越权 404（profile 集成测试）
- 1.3 添加教材后只保存改过的专业课（App 测试）
