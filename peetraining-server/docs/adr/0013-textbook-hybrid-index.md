# ADR 0013：官方教材双索引与代次发布

日期：2026-10-30；状态：采用（真实外部服务验收待 T43）

## 决策

中文全文使用既有 MySQL 8 InnoDB `FULLTEXT(body,heading) WITH PARSER ngram`；语义向量使用独立私有 Qdrant 的 Cosine 集合及索引，Go 标准 HTTP 客户端接入，无新增 Go 依赖。不能用 JSON 向量全表扫描替代向量索引。MySQL 保留可重建的权威原文、切片位置、代次配置与发布指针。

每个构建代次有独立 Qdrant 集合，名称由 profile 摘要和代次 ID 组成；payload 明确携带 book/edition/revision/generation。查询在向量服务施加强过滤，取回后仍对 MySQL 的片段、正文 hash 和单元字符偏移校验。集合数量随代次增长，首版保留历史，不自动清理；规模扩大前须评估迁移为 profile 集合及旧代次 GC，历史引用依赖 MySQL 摘录快照而不是 Qdrant。

嵌入 profile 包含 provider、无凭证端点、model、dimensions、verbatim-v1 预处理。凭证不进 profile、数据库或 API；轮换密钥不触发重建。查询必须匹配文档 profile，配置变化先创建新代次，不能把新模型查询向量发到旧模型集合。跨 profile 的历史线上查询在可配置旧客户端接入前降级，不混维查询。

按原文单元及中文标点切片，不跨单元/版本；配置化长度和重叠，片段保留完整文本及 rune 起止、sha256。RRF-v1 融合各自排名，不把全文分和距离当概率。后台试检索展示真实召回；答案相关性、充分/部分/无依据及实际引用另在 T41 校验。

Worker 检查点在每段向量确认写入之后落 MySQL。重复写同 ID 幂等；故障续跑可重复一次外部调用但不会重复片段。任务先持久化再入队，定时恢复；会话锁避免同代次重复并行。发布前核对校对/原文、完整双索引、profile 与授权，再持有书籍/版本/修订行锁切换指针，记录不可覆盖事件。

APP 新检索使用独立 `textbook_retrieval` 灰度开关（默认关闭），与官方题库独立。管理后台角色仍是 admin/content_lead。

## 代价与验收边界

新增 Qdrant 私有服务、持久卷、独立 API key 与备份操作。MySQL 全文需要 ngram 插件；索引构建错误必须阻止发布。默认检索参数是开发值，需要授权真实样本评测后版本化调整。HTTP mock 与模拟嵌入只能验状态/协议，不能证明真实服务连通、召回率、费用或时延达标。
