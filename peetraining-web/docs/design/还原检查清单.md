## 一、需要先拍板或处理的（影响上线）

- [ ] **生产环境短信没开，没人能登录**。截图里点「获取验证码」出现「该功能暂未启用」，原因是服务端 `SMS_PROVIDER=disabled`。在应用机环境变量里改成 `aliyun`，并配好 `SMS_SIGN_NAME`、`SMS_TEMPLATE_CODE`（凭证复用 `ALIYUN_ACCESS_KEY_ID / SECRET`），重启 API。另外建议把这条报错文案改成「短信服务维护中，请稍后再试」，不要让用户看到「功能未启用」。
- [ ] **启动页（0.1）用哪套**：现在仍是 VI 竖版组合（夜靛底、琥珀「考研」）；设计稿 m0_splash 是白底 + 黑色图标。按「主色只用于 Logo」的原则可以改成白底 + VI Logo，待确认。
- [ ] **数字字体**：设计稿数字用 DM Sans，App 打包的是 Sora（截图里「105」就是 Sora，字形更宽更圆）。要一比一就换成 DM Sans（开源 OFL 授权，两个字重约 100 KB），待确认。
- [ ] **目标分步进（1.2 / 2.1f）**：设计稿按钮是「减 1 / 加 1」，App 现在一次加减 5，待确认。
