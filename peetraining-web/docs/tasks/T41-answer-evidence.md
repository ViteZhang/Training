## 目标与范围
- 全部现有AI答案入口复用官方教材优先/个人资料补充/通用知识兜底；仅用户指定明确版本；未匹配和检索故障静默。
- 独立语义相关性筛选、依据覆盖与引文支持校验，实际采用来源保存不可变快照；最终写事务再次锁定授权/可用性。
- 保留已有答案；单题与导入并发不重复扣次、不互相覆盖。批改保留答案/来源版本快照。
- 主动更新采用持久异步候选，成功扣一次、采用不扣、失败不扣、放弃不退。幂等、冲突与来源撤销校验。
