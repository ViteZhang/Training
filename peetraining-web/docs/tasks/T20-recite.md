## 记录（开发中填写）

- 实现要点：
  - 契约 v0.7.0（只加不改）：createReciteSession、getReciteSession、recordRecite、requestReciteAudioUpload、finishReciteSession
  - 背诵队列：有原文表述的知识点；今日计划背诵组里的优先，其余从没背过或背诵复习日已到的按掌握分从低到高，一轮最多 10 条；当天进行中的一轮可继续；「再背没记住的」只取那一轮最后结果为没记住的
  - 挖空：采分关键词取采分点上标注的关键词，没有时用原文里找得到的采分点内容，再没有时按标点切出 2–10 字短语；原文按关键词切段（互不重叠，拼起来就是原文）
  - 默写与口述：关键词比对（规则，不调模型，PRD 12.1）：去掉空白与标点后包含即算写到；全部写到为记住了，过半为模糊，其余没记住
  - 口述：录音直传到用户前缀 → 语音识别 → 关键词覆盖；功能开关 oral_recite（默认关闭，可只对指定用户打开），关闭时上传与记录都返回 404
  - 学习状态：背诵按 PRD 11.1 改掌握分（记住了 +8、模糊 +2、没记住 −8），按 11.3 排独立的背诵复习日（没记住 1 天后并重置、模糊 2 天后、记住了 3 → 7 → 15 → 30 天），不算作答验证；每条记录带幂等键（迁移 00012）
  - 背诵完成：按每条最后一次结果统计记住 / 模糊 / 没记住，与同一门课上一轮对比，给出明天 / 2 天后 / 3 天以后的条数
  - 修复（T16）：没记住的知识点复习档位归零后被今日计划当作「从没背过」、当天又出现；改为按背诵复习日判断，次日才进背诵组；训练首页的待背条数与背诵队列用同一口径
  - App：4.14 挖空（点空格查看、全部显示、三档自评）、4.15 默写结果（关键词覆盖、对照原文写对标绿遗漏标红）、4.16 口述（开关打开才显示；点击开始 / 结束录音、计时、上传后显示识别文字与覆盖）、4.17 背诵完成（与上一轮对比、复习安排、再背没记住的）、麦克风权限先说明再申请；训练页「背诵」入口接通
