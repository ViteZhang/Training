# 拍照、语音、微信导入与引导优化验收清单

本次包含前一轮未提交的模拟考试拍照后台识别，以及微信分享导入、语音输入、满分和年份交互优化。

## 验收前准备

1. 后端依次执行迁移00027、00028后，再部署对应API和Worker。未执行迁移时不要将云效后端代码合并到会自动发布的main。
2. 安装本分支重新生成的原生App安装包；微信分享扩展和录音不以旧安装包或Expo Go验收。
3. 配置 `ASR_PROVIDER=bailian`、`ASR_MODEL=qwen3-asr-flash`、百炼地址及凭据，对验收账号打开 `voice_answer`。关闭时语音入口应隐藏。
4. 准备至少三道主观题的模拟试卷、两页手写答案、两段含专业术语的语音，以及PDF、docx、xlsx、图片各一份。另准备两个同名文件。

## 逐项验收

| 编号 | 操作 | 预期结果 |
| --- | --- | --- |
| 1 | 模拟考试拍手写稿，查看右侧识别字数；放大系统字体至1.3倍 | 字数与按钮对齐，文字不被截断 |
| 2 | 第1题拍完照片，上传或识别尚未完成时立即进入第2题并作答 | 可继续答题；照片和任务保留在第1题，不覆盖第2题答案 |
| 3 | 通过答题卡回第1题，修改识别文字，切题再返回，再确认 | 编辑保留；确认只追加一次，原有文字答案保留 |
| 4 | 同题拍两页，模拟第一页上传较慢；等待结果后确认或交卷 | 显示、拼接按拍摄顺序排列，不按上传完成顺序排列 |
| 5 | 拍照后断网，再切题、返回、重启App、恢复网络后重试 | 本机照片可找回；使用同一任务恢复，不必重拍，不重复追加 |
| 6 | 照片上传未完成时手动交卷；再测试已登记但仍识别中的交卷 | 未保存到服务端时等待或提示重试；已登记的任务随答卷进入后台，识别完默认采用，再批改 |
| 7 | 故意让识别失败，分别尝试重试与弃用 | 原文件保留；失败不被静默当作空白答案，用户可重试或明确弃用 |
| 8 | 临近考试截止拍照／录音，观察自动交卷 | 已登记内容继续后台处理；未在截止前登记的内容保留本机并提示未计入，不延长考试时间 |
| 9 | 交卷后离开页面，从历史答卷返回；遇到批改中断时恢复批改 | 可找到已交答卷，看到识别／批改状态；重试不重复扣除批改次数 |
| 10 | 打开导入页、补充答案页的“从微信导入” | 展示下载文件、右上角“…”、其他应用打开／分享、选择本App步骤；提供“更多”和保存手机文件的备用路径 |
| 11 | iPhone从微信分享文件，点“保存待导入”，返回App；Android测试分享和其他应用打开 | 收到文件并保存本机，显示待导入提醒，可选择专业课及题目／资料／补充答案 |
| 12 | 未登录时分享文件，再登录；正在模拟考试时接收；取消选课后重进 | 文件保留，不强制中断考试；选择课程与用途并确认后才上传 |
| 13 | 分别导入PDF、docx、xlsx、图片、同名文件；测试超限和部分失败后重试 | 类型与限制提示正确；同名文件分别保留，成功文件不因失败重试重复回灌 |
| 14 | 练习和模拟考试开启语音输入，先拒绝麦克风，再允许；停止录音后立即切题 | 权限说明和恢复入口正常；录音留在原题，后台上传、调用Qwen语音模型转写 |
| 15 | 同题录两段，核对专业术语、原话和顺序，编辑后确认；重复点击或重试 | 只转写原话，允许核对；按录制顺序拼接，结果不重复追加 |
| 16 | 练习中录音尚未识别完时提交；识别完成后不点确认直接提交 | 未完成时提示等待／重试；完成后默认采用识别结果，再提交批改 |
| 17 | 模拟考试录音未识别完时交卷，随后返回历史答卷 | 等待上传登记后可交卷；后台识别默认采用后再批改，可回历史查看 |
| 18 | 新增专业课后进入目标分，不点击满分按钮直接下一步；再改100或300分 | 150分默认明确选中，默认目标分105；无需额外点击，修改后正确保存 |
| 19 | 注册后选择考试年份，打开选择框、切换年份，再离开和返回；检查备考设置页 | 默认最近未结束的一届研考；底部纵向列表完整显示年份及实际考试日期，已有有效选择保留 |
| 20 | 关闭语音开关，并回归普通打字、拍照作答、资料导入及模拟考试计时 | 语音入口隐藏；原功能可用，本题计时继续变化，切题后累计时间正常 |
