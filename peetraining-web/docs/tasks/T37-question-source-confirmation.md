# T37 导入题目来源确认与真题归属

- 仓库：后端 + 前端（接口契约先行）
- 依赖：T10、T12、T13、T14、T21、T22、T35
- 计划完成：10/29
- 状态：开发完成（待数据库集成与真机验证）

## 目标

题目来源必须由用户确认。识别年份只补充年份信息，不得把习题或来源待确认题自动变成历年真题。

## 范围

- 后端：题目文件来源写入导入任务；结构化结果继承文件来源；待确认条目允许逐题修正；新增 `unconfirmed` 来源；迁移无法证明已确认的旧导入真题；年份修复和题目编辑不再自动修改来源。
- 后端：真题卷、真题考情与预估分样本仅使用确认过的真题；已有试卷历史 session、作答与报告保持可读。
- 前端：题目导入按文件选择历年真题、习题或暂不确定；未选择来源不能开始解析；1.7 可逐题修正来源；题库列表与详情显示并可筛选来源待确认。
- 兼容：旧版客户端未提交文件来源时按来源待确认处理；非题目模式拒绝题目来源字段。

## 验收

- 同一导入任务中的不同文件可选择不同来源，失败重试保留来源；未选择来源不能开始解析。
- 年份、题号、文件名和 AI 结果都不能自动确定来源；题目级来源可覆盖文件默认值。
- 来源待确认题可普通练习，但不能进入新真题卷、真题考情或真题卷估分。
- 修改年份不改变来源；将来源改为真题或习题后，受影响年份的真题卷和考情重算。
- 存量迁移只把带资料出处的用户导入真题改为来源待确认；官方题、手工题和 session 报告保持原值。
- 后端 `make gen`、`make test`、`make lint`；前端 `pnpm typecheck`、`pnpm lint`、`pnpm test` 通过。
