# T40 混合检索、索引与发布
- 仓库：server + web；依赖：T38、T39；状态：代码已实现，真实外部服务验收待 T43
## 目标
把已校对教材构建为可追溯的全文与向量索引，支持后台试检索及安全发布。
## 范围
- 独立 OpenAI embeddings 配置（1024 维默认），严格向量响应验证，服务端密钥。
- MySQL ngram 全文 + Qdrant HNSW，按修订及索引代次隔离，切片保留单元和字偏移。
- 异步构建、检查点与恢复；配置变化新代次；校对修改失效；失败保留旧线上。
- 后台索引状态、检索试用、原子发布、默认版次、下架、授权与摘录展示控制。
- 教材检索独立功能开关默认关闭；试用不访问用户内容，不扣用户额度。
## 验收
- 嵌入协议、非法维度/数值/缺失与重复索引、超时错误测试。
- 全文与向量召回及 RRF 融合；跨版本/代次、旧配置、非就绪草稿拒用。
- 幂等构建/恢复、并发编辑与发布、授权/下架竞态及旧线上保留。
- 契约重新生成；Go/TS 检查；后台真实浏览器流程。
## 不做
T41 的答案生成/候选与额度、T42 APP 与旧素材迁移；真实服务验收记录在 T43。未经授权不部署生产。
